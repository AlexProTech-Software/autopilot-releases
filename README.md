# Alex ProTech — Autopilot

Официальные установщики Autopilot Setup для Windows и Autopilot Bridge для Android.

[Скачать актуальную версию](https://github.com/AlexProTech-Software/autopilot-releases/releases/latest)

## Первое подключение к обновлениям

1. Откройте страницу актуального выпуска.
2. Для Windows скачайте файл AutopilotSetup-*.exe. Для планшета скачайте AutopilotBridge-*.apk и установите поверх существующего Bridge.
3. Откройте программу. Bridge подготовьте кнопкой «Подготовить Bridge», подтверждая запросы Android.

## Последующие обновления

Программы проверяют новую версию при запуске. Когда обновление доступно, нажмите «Обновить». Настройки сохраняются. На Android подтвердите системную установку и снова откройте Bridge.

Обновляйте программы после завершения обслуживания планшета. Для Bridge сначала нажмите СТОП.

Выпуски содержат описание изменений и статус проверок. Первое обновление на реальном планшете пока не испытано.

Файл stable.json нужен программам для автоматической проверки версии; пользователю открывать его не требуется.
